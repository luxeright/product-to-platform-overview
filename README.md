# Product-to-Platform

An adaptive AI skill for founders and product teams moving from a product problem to architecture, delivery and operational readiness.

## What it helps you do

- Clarify the problem, intended users, outcomes and smallest useful scope.
- Learn through adaptive coaching that builds on saved decisions and evidence.
- Review work through four perspectives: Product, Design, Engineering and Platform Architecture.
- Navigate G0–G8 decision gates, from scope through operation, expansion and retirement.
- Compare AI with deterministic alternatives, define quality benchmarks and assess cost per successful generation.
- Check architectural claims against actual repository files, APIs, tests and migrations.
- Plan reusable platform capabilities with discoverability, documentation, versioning and adoption measures.
- Produce consistent reviewer artifacts with evidence, acceptance criteria and stop conditions.

## Example request

> I have an existing app and a new feature idea. Help me test whether the problem is worth solving, compare approaches, and prepare a thin delivery plan. Review the relevant repository evidence, preserve unresolved risks, and explain what can proceed and what needs an owner decision.

## What the full package includes

The full v2.2 package contains the skill instructions, four reviewer guides, adaptive coaching and state support, focused review modules, reusable templates, and a JSON reviewer contract with a validation helper.

The instructions are written in Markdown and can be supplied to assistants that support custom instructions or skills. File access, saved state, terminal tools and integrations depend on the host environment. Cross-assistant behavior has not been independently validated.
